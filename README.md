# MANGALAM-AGRO-INDUSTRIES — Mannat Chai

Marketing website for Mannat Chai, India's favourite tea.

Static site — just open `index.html` in a browser, or serve the folder with any
static host.

## Files

- `index.html` — page markup
- `styles.css` — styles
- `script.js` — size selector, 3D pack showcase, mobile menu
- `assets/` — logo, product art, and imagery
